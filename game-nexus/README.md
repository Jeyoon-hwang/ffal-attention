# 🥋 NEXUS 무협 - 3D 동양 판타지 액션 RPG

## 게임 정보

**NEXUS 무협**은 강호의 고수 무사가 되어 정파와 사파의 싸움 속에서 생존하는 3D 액션 게임입니다.

- **플랫폼**: PC (Windows, macOS, Linux)
- **엔진**: Godot 4.6.2
- **장르**: 3D Action RPG (무협)
- **상태**: 개발 중 (Week 1-2)

---

## 🎮 게임 특징

### 핵심 메커닉
- 🥋 **콤보 시스템**: 최대 3단계 콤보로 데미지 증가
- ⚡ **무술 스킬**: 강력한 스킬로 적을 처치
- 🔥 **내공 시스템**: 공격력 1.5배 강화 (Q키)
- 👥 **파당 시스템**: 정파/사파/독립 캐릭터 특성
- 👑 **보스 전투**: 어려운 보스와의 긴박한 전투

### 게임플레이
- 무한 웨이브 시스템 (스테이지 무한 반복)
- 스테이지마다 난이도 15% 증가
- 높은 점수를 목표로 생존 경쟁
- 콤보 보너스로 추가 점수

## 🎮 조작 방법

| 조작 | 기능 |
|------|------|
| **W/A/S/D** | 이동 |
| **마우스** | 시점 조절 |
| **Space** | 점프 |
| **좌클릭** | 기본 공격 (콤보) |
| **우클릭** | 무술 스킬 |
| **Q** | 내공 활성화 |
| **ESC** | 일시정지/메뉴 |

## 📊 게임 통계

### 플레이어 스탯
- **체력**: 120 HP
- **에너지**: 100 (회복 가능)
- **이동속도**: 12 m/s
- **기본 공격**: 20 대미지
- **무술 스킬**: 45 대미지

### 스테이지별 진행
- **적 개수**: 5명 + 1명 보스
- **난이도 배수**: 초기 1.0 → 매 스테이지 +15%
- **보상**: 점수 (스테이지 × 100)
