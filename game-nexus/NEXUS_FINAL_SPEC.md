# 🥋 NEXUS 무협 오픈월드 - 최종 프로젝트 명세서

## 게임 개요

**NEXUS 무협 오픈월드**는 플레이어가 광활한 오픈월드에서 고대 무술들을 발견하고 조합하여 세상에 없던 새로운 무술을 창조하는 게임입니다.

## 🎮 게임 특징

### 1. 무술 생성 엔진 (Martial Arts Generator)
```
기초 × 스타일 × 패턴 × 효과 = 수백만 가지 무술
10개 × 20개 × 30개 × 50개 = 300만 가지 기본 조합
+ 고급 조합 = 수백만 개
```

**무술 요소**:
- **기초** (10개): 주먹, 발, 검, 채, 손가락, 팔, 다리, 머리, 내력, 기운
- **스타일** (20개): 강경, 부드러움, 빠름, 느림, 날카로움, 둔함, 우아함, 야만, 섬세함, 폭발, 조용함, 우렁참, 회전, 직선, 곡선, 연계, 단순, 복잡, 침착, 광기
- **패턴** (30개): 일직선, 원형, 대각선, 지그재그, 나선형, 파동, 폭발, 집중, 산포, 다단, 관통, 광선, 충격, 진동, 뒤틀림, 얼음, 불, 바람, 땅, 어둠, 빛, 독, 생명, 정신, 시간, 공간, 중력, 음파, 기운, 영혼
- **효과** (50개): 타격, 내력, 회전, 파동, 연쇄, 폭발, 절단, 관통, 부수기, 마비, 감속, 중독, 화상, 결빙, 혼란, 공포, 흡수, 강화, 약화, 반사, 방어, 회피, 이동, 비행, 치유, 부활, 현혹, 분신, 차원, 운명, 무한, 등등

### 2. 오픈월드 (100km²)
```
5개 지역:
├─ 중원 (평원) - 메인 지역
├─ 서역 (사막) - 신비로운 지역
├─ 남해 (섬) - 수상 지역
├─ 북국 (설산) - 험난한 지역
└─ 동녕 (숲) - 미스터리 지역

500개 랜드마크:
├─ 10개 도시
├─ 50개 마을
├─ 30개 사원
├─ 100개 유적
└─ 300개 자유 탐험 지역

50개 던전:
├─ 난이도 1-100 스케일
├─ 다양한 생태계
└─ 진행형 보상
```

### 3. 무술 발견 시스템 (500개+ 고서)
- **고서 발견**: 세상에 숨겨진 500개+ 고서 찾기
- **NPC 학습**: 200명의 마스터에게 무술 배우기
- **던전 탐험**: 고대 유적에서 전설의 무술 발견
- **전투 경험**: 강한 적과 싸우며 기술 습득
- **자각 창조**: 배운 무술 조합으로 새 무술 발명

### 4. 무술 조합 UI
- **실시간 미리보기**: 요소 선택하면 즉시 무술 확인
- **스탯 계산**: 자동으로 대미지, 속도, 정확도 계산
- **색상 코딩**: 각 무술의 비주얼 스타일 자동 생성
- **이름 커스터마이징**: 플레이어가 무술 이름 지정

## 🎯 주요 시스템

### 무술 생성 알고리즘
```gdscript
func create_martial_art(bases, styles, patterns, effects):
    ma.damage = calculate_from_bases(bases) * 
               calculate_from_styles(styles)
    ma.speed = calculate_speed(bases, styles)
    ma.accuracy = calculate_accuracy(effects)
    ma.cooldown = 1.0 + (요소수 * 0.1)  # 밸런싱
    return ma
```

### 오픈월드 스트리밍
```gdscript
func stream_nearby_landmarks(radius):
    for landmark in all_landmarks:
        if distance(player, landmark) < radius:
            load(landmark)
        else:
            unload(landmark)  # 메모리 절약
```

```
고서 발견 → 무술 요소 습득 → 도감 추가 → 조합 가능
```
