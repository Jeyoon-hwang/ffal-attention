## 💡 주요 시스템

### 전투 시스템
```
좌클릭 → 기본 공격
├─ 1히트: 20 대미지 (콤보 1)
├─ 2히트: 26 대미지 (콤보 2)
└─ 3히트: 32 대미지 (콤보 3)

우클릭 → 무술 스킬 (45 대미지, 에너지 30 소비)
Q → 내공 활성화 (공격력 1.5배)
```

### 파당 시스템
```
정파: 난이도 100% (기본)
사파: 난이도 80% (빠르지만 약함)
독립: 난이도 120% (강하지만 느림)
보스: 난이도 200%+ (모든 스킬 사용)
```

### 스테이지 진행
```
Stage 1 (난이도 1.0) → 5명 적 + 보스
↓
Stage 2 (난이도 1.15) → 5명 적 + 보스
↓
Stage 3 (난이도 1.30) → ...
...
∞
```
