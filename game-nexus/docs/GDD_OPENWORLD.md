# NEXUS 무협 오픈월드 - Game Design Document

## 1. 게임 개요

### 게임명
**NEXUS 무협 오픈월드** - 무술 창조 액션 RPG

### 플랫폼
PC (Windows, macOS, Linux)

### 장르
Open World Action RPG with Dynamic Martial Arts Creation

### 핵심 콘셉트
플레이어는 광활한 오픈월드에서 수천 년의 역사 속에 잊혀진 무술들을 발견하고,
이를 조합하여 세상에 없던 새로운 무술을 창조하는 게임.

---

## 2. 게임 메커닉

### 2.1 무술 시스템 (Martial Arts Engine)

#### 무술의 구조
모든 무술은 다음 요소의 조합으로 이루어짐:

```
무술 = 기초 (Base) + 스타일 (Style) + 패턴 (Pattern) + 효과 (Effect)

기초: 주먹, 발, 검, 채, 손가락 등 (10가지)
스타일: 강경, 부드러움, 빠름, 느림, 날카로움 등 (20가지)
패턴: 일직선, 원형, 대각선, 복합 등 (30가지)
효과: 타격, 내력, 회전, 파동, 조합 등 (50가지)
```

**조합 가능성**: 10 × 20 × 30 × 50 = **30만 가지**

추가로 고급 조합으로 **수백만 가지** 가능

#### 무술 레벨
```
Tier 1: 기초 무술 (1가지 요소)
Tier 2: 초급 무술 (2-3가지 요소 조합)
Tier 3: 중급 무술 (4-5가지 요소 조합)
Tier 4: 고급 무술 (6-8가지 요소 조합)
Tier 5: 최고 무술 (9-10가지 요소 조합)
```

### 2.2 무술 발견 시스템

#### 어디서 찾을까?
1. **고서 & 비석**: 세상에 숨겨진 고서에서 무술 비법 발견
2. **NPC 스승**: 고수 NPC에게 무술 배우기
3. **유적 탐험**: 던전/사원에서 고대 무술 발견
4. **전투로부터**: 강한 적과 싸우며 그들의 기술 배우기
5. **자각 & 깨달음**: 장시간 수련으로 새로운 무술 발명

#### 발견 보상
```
고서 1개 → 무술 요소 1-3개 얻음
NPC와 전투 → 상대의 무술 기초 배움
유적 탐험 → 희귀 무술 발견
조합 성공 → 완전히 새로운 무술 창조
```

### 2.3 무술 창조 시스템

#### 무술 조합
발견한 무술 요소들을 조합하여 새로운 무술 창조:

```
기초 무술 1 + 기초 무술 2 → 새 무술 생성
예: [주먹 기초] + [빠른 스타일] = "신속권"
```

#### 조합 규칙
- 최소 2개, 최대 10개 요소 조합 가능
- 조합마다 새로운 무술 생성
- 같은 조합은 같은 무술 (중복 방지)
- 희귀 요소 조합 → 더 강한 무술

#### 무술 커스터마이징
```
무술 이름: 직접 지정 가능
무술 설명: 자동 생성 또는 커스텀
무술 색상: 비주얼 스타일 선택
무술 효과: 파티클 커스터마이징
```

## 3. 오픈월드 구조

### 3.1 세계 설정
- **배경**: 고대 무협 세계 (5000년 역사)
- **지역**: 5개 대륙
  - 중원 (메인 지역)
  - 서역 (사막 지역)
  - 남해 (섬 지역)
  - 북국 (설산 지역)
  - 동녕 (미스터리 지역)

### 3.2 맵 크기
- **전체**: 100km² 오픈월드 (실시간 로드 없음)
- **이동**: 걷기, 뛰기, 비행 가능
- **탐험**: 약 500개 랜드마크

### 3.3 오픈월드 요소
```
도시: 10개
마을: 50개
사원: 30개
던전: 50개
유적: 100개
자유 탐험 지역: 무한
```

## 4. 게임 루프

### 4.1 메인 게임루프

```
1. 오픈월드 탐험
   ├─ 고서 발견 → 무술 요소 습득
   ├─ NPC 만남 → 무술 학습
   ├─ 강적 전투 → 기술 학습
   └─ 유적 탐험 → 고대 무술 발견

2. 무술 창조
   ├─ 무술 요소 선택
   ├─ 조합 시뮬레이션
   ├─ 새 무술 창조
   └─ 무술 이름/스타일 커스터마이징

3. 수련 & 강화
   ├─ 무술 경험치 축적
   ├─ 무술 레벨 업
   ├─ 새로운 효과 언락
   └─ 궁극 기능 습득

4. 전투 & 도전
   ├─ NPC와 대전
   ├─ 던전 클리어
   ├─ 보스 전투
   └─ 기술 증명
```

### 4.2 승리 조건
- 특정 무술 창조 (스토리 목표)
- 최강 무술 개발 (개인 목표)
- 모든 무술 요소 수집 (컬렉션)
- 5000개 이상 무술 창조 (무한 도전)

## 6. 핵심 시스템

### 6.1 무술 발견 시스템
- **자동 로깅**: 발견한 모든 무술 자동 기록
- **도감 UI**: 발견한 무술 열람 가능
- **진행률 추적**: 몇 % 발견했는지 표시
- **희귀도**: 발견 확률에 따른 무술 등급

### 6.2 무술 조합 인터페이스
```
[선택된 요소들]
├─ 기초: 주먹 (선택 가능)
├─ 스타일: 빠름 (선택 가능)
├─ 패턴: 일직선 (선택 가능)
├─ 효과: 타격 (선택 가능)

[실시간 미리보기]
├─ 무술 이름 제안
├─ 스탯 계산
├─ 비주얼 이펙트 미리보기
└─ 창조 가능 여부 판단
```

### 6.3 수련 시스템
```
무술 경험 축적
├─ 전투 사용 → XP 획득
├─ 수련 모드 → XP 2배
├─ NPC 지도 → XP 3배
└─ 레벨 업 → 새 효과 언락

최대 레벨: 100
최대 효과: 10개
```

## 7. 오픈월드 콘텐츠

### 7.1 NPC & 스토리
- **주요 NPC**: 20명 (각 지역 스승)
- **일반 NPC**: 200명 (퀘스트, 상점 등)
- **보스**: 50명 (강력한 무사)

### 7.2 퀘스트
```
메인 퀘스트: 전설의 무술 창조 (50개)
서브 퀘스트: 지역별 도전 (500개+)
일일 퀘스트: 매일 변하는 도전
숨겨진 퀘스트: 비석/고서 조건으로만 열림
```

### 7.3 던전 & 유적
```
던전 구조:
├─ 쉬움 (1-10 난이도)
├─ 보통 (11-30 난이도)
├─ 어려움 (31-50 난이도)
├─ 극악 (51-100 난이도)
└─ 미스터리 (무한 난이도)

보상:
├─ 무술 요소 (10-50개)
├─ 고급 요소 (희귀)
├─ 장비 & 아이템
└─ 경험치 & 금전
```

## 10. 게임의 특수성

### 엄청난 자유도
- 플레이어가 직접 무술 창조
- 수백만 가지 무술 조합
- 세상에 없던 기술 발명 가능

### 무한 콘텐츠
- 무술 발견은 끝이 없음
- 조합 변수가 천문학적
- 매번 다른 경험

### 오픈월드 깊이
- 1000시간 이상 플레이 가능
- 100% 완료는 거의 불가능
- 항상 발견할 것이 있음
