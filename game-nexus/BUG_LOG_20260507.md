### Bug #1: 보스 아레나 범위 정의 안 됨

**심각도**: 🟡 중간  
**발견자**: 코드 분석 (Day 1)  

**증상**:
```
- 보스 전투 영역이 시각적으로만 표현됨
- 실제 플레이에서 보스가 맵 경계를 벗어날 수 있음
- 플레이어가 보스 전투 도중 탈출 가능
```

**원인**:
```
game_manager.gd에서 보스 스포닝 위치만 정의되고,
보스 전투 영역(collision zone)이 없음
```

```gdscript
# zhongyuan_hub.tscn 생성 시

├─ CSGBox3D (barrier) - 벽
│  └─ collision enabled
├─ CSGBox3D (floor) - 아레나 바닥
└─ Node3D (boss_spawn_point)
```

**테스트 기준**:
```
✅ 보스 아레나 경계가 명확함
✅ 보스/플레이어가 경계를 벗어날 수 없음
✅ 전투 중 자유로운 이동 가능 (원형 범위)
```

### Bug #2: 파티클이 메모리에 누적됨
**상태**: 🔍 잠재적 버그  
**심각도**: 🟡 중간  
**예상 문제 시점**: 10분 이상 플레이 시

**증상** (예상):
```
- 10분 플레이 후 FPS 저하 (60fps → 40fps)
- 메모리 사용 계속 증가 (누수)
- 파티클이 화면에 보이지 않는데도 계속 존재
```

**원인** (잠재적):
```
Player.spawn_particle_hit()에서 파티클을 생성만 하고,
queue_free() 타이밍이 부정확할 수 있음
```

**예방 방법** (Day 2 Mission 3에서):
```gdscript
func spawn_particle_hit(position: Vector3, color: Color, count: int = 8):
    var particle = GPUParticles3D.new()
    particle.position = position
    particle.lifetime = 0.3
    add_child(particle)
    
    # 명시적 타이밍
    await get_tree().create_timer(particle.lifetime).timeout
    if is_instance_valid(particle):
        particle.queue_free()

# 또는 자동 제거 (권장)
func spawn_particle_hit_auto(position: Vector3, color: Color):
    var particle = load("res://src/scenes/particle_effects/basic_hit.tscn").instantiate()
    particle.position = position
    add_child(particle)
    # particle.tscn에서 자동 제거 설정됨
```

**테스트 기준**:
```
✅ 30분 플레이 후 FPS 안정 (50fps+)
✅ 메모리 250MB 이내
✅ 콘솔에 "leaked particle" 경고 없음
```

**상태**: 🔄 테스트 필요  
**심각도**: 🟡 중간  

**현재 설정**:
```gdscript
const ENEMY_DODGE_CHANCES = {
    4: 0.7  # 신급: 70% 회피율
}
```

**문제점**:
```
- 신급 적을 상대하려면 10회 공격이 필요 (7회 회피)
- 플레이어 입장에서 공격이 자주 무시됨
- 게임이 답답해 보일 수 있음
```

**해결 방법** (Day 2 테스트 중 조정):
```gdscript
# Option 1: 회피율 감소
const ENEMY_DODGE_CHANCES = {
    4: 0.5  # 70% → 50% (5회 중 2-3회 회피)
}

# Option 2: 회피는 높지만 카운터 추가
func try_dodge() -> bool:
    if randf() < dodge_chance:
        print("회피!")
        if randf() < counter_chance:  # 회피 후 카운터 시도
            attempt_counter()
        return true
    return false
```

**테스트 기준**:
```
✅ 신급 적 처치에 평균 15-20초 소요 (합리적)
✅ 플레이어가 무력감을 느끼지 않음
✅ 신급은 여전히 강함 (중급보다 2배)
```

### Bug #4: 보스 패턴 타이밍이 고정됨
**상태**: 🔍 설계 단계  
**심각도**: 🟡 중간  

**문제점**:
```
- 보스가 항상 같은 패턴 순서를 사용 (예측 가능)
- 게임이 반복적으로 느껴짐
- 난이도 곡선이 고정적
```

**해결 방법** (Day 2 Mission 2에서):
```gdscript
# boss_ai.gd
func get_recommended_pattern_by_distance(distance: float, hp_percent: float) -> String:
    """거리와 체력에 따른 패턴 선택"""
    
    var pattern_weights = {}
    
    # 거리별 선호도
    if distance > 8:
        pattern_weights["기본_공격"] = 1.0  # 접근
    elif distance < 3:
        pattern_weights["회전_공격"] = 1.2  # 광역
    
    # 체력별 추가
    if hp_percent < 0.4:
        pattern_weights["강력_슛"] = 1.5  # 절체절명 모드
    
    # 랜덤성 추가
    var weights = []
    for pattern in pattern_weights.keys():
        for i in range(int(pattern_weights[pattern] * 10)):
            weights.append(pattern)
    
    return weights[randi() % weights.size()]
```

**테스트 기준**:
```
✅ 같은 보스 전투를 여러 번 해도 패턴이 다름
✅ 여전히 깨질 수 없음 (밸런싱)
✅ 게임이 동적으로 느껴짐
```

### Bug #6: 에너지 회복이 느림
**상태**: 🔄 조정 중  
**심각도**: 🟢 낮음  

**현재 설정**:
```gdscript
const PLAYER_ENERGY_RECOVERY_RATE = 2.5  # 초당
```

**느낀 문제** (예상):
```
- 스킬 사용 후 (에너지 -30)
- 회복에 12초 필요 (30 / 2.5)
- 너무 오래 기다려야 함
```

**개선 아이디어**:
```gdscript
# Option 1: 회복율 증가
const PLAYER_ENERGY_RECOVERY_RATE = 4.0  # 2.5 → 4.0

# Option 2: 콤보하면 에너지 회복
func basic_attack():
    # ... 기존 코드 ...
    if current_combo > 1:
        energy += 2  # 콤보하면 에너지 +2

# Option 3: 시간별 차등 회복
if energy < 20:
    recovery = 5.0  # 낮을 때 빠름
elif energy < 50:
    recovery = 3.0
else:
    recovery = 2.0  # 높을 때 느림 (밸런싱)
```

**테스트 기준**:
```
✅ 스킬 사용 후 회복 시간 7-8초 (합리적)
✅ 스킬 연타 플레이 가능
```
