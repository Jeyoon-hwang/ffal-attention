**설계 내용**:
```
🐉 명월검사 (중원 첫 보스)

스펙:
  ├─ 체력: 280 HP
  ├─ 공격력: 30
  ├─ 레벨: 2 (중급)
  └─ 특징: 3가지 패턴 사용

패턴 1: 기본 연타
  ├─ HP 범위: 100% ~ 70%
  ├─ 동작: 플레이어 추격 → 3회 공격
  ├─ 데미지: 30 × 3 = 90
  ├─ 쿨타임: 1.5초
  └─ 플레이어 전술: 회피 또는 역공격

패턴 2: 광역 회전
  ├─ HP 범위: 70% ~ 40%
  ├─ 동작: 원자리 회전 → 8m 범위 광역
  ├─ 데미지: 40 × 2 = 80
  ├─ 쿨타임: 2.5초
  └─ 플레이어 전술: 거리 유지 또는 회피

패턴 3: 강력 슷
  ├─ HP 범위: 40% ~ 0%
  ├─ 동작: 차징 → 강력 슷 → 넉백
  ├─ 데미지: 50 (높음)
  ├─ 쿨타임: 3초
  └─ 플레이어 전술: 치명적 - 절체절명 모드

패턴 선택 로직:
  ├─ 거리 기반: 멀면 추격, 가까우면 광역
  ├─ 체력 기반: 체력 낮을수록 강한 패턴
  └─ 랜덤성: 같은 패턴 반복 방지
```

**구현 가능성**:
- boss_ai.gd의 기초 구조가 이미 있음
- 패턴 함수만 추가하면 됨 (+100줄)
- 게임 밸런싱 검증 필요
