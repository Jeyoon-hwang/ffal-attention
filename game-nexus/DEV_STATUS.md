# NEXUS - 개발 현황 보고

## 프로젝트 정보
- **게임명**: NEXUS (사이버펑크 3D 액션 게임)
- **엔진**: Godot 4
- **플랫폼**: PC / Mobile / VR
- **장르**: 3D Action RPG
- **개발 상태**: 초기 개발 단계

## 완료된 시스템

### 1. 플레이어 시스템 ✅
- **파일**: `src/scripts/player.gd`
- **기능**:
  - WASD 이동 (8방향)
  - 마우스 시점 조절
  - 점프 메커닉
  - 근거리 공격 시스템
  - 체력 관리
  - 피해 시스템

### 2. 적 AI 시스템 ✅
- **파일**: `src/scripts/enemy.gd`
- **기능**:
  - 플레이어 감지 (20m 범위)
  - 추격 AI
  - 근거리 공격
  - 체력/사망 시스템
  - 상태 머신 (idle/chase/attack)

### 3. 게임 매니저 ✅
- **파일**: `src/scripts/game_manager.gd`
- **기능**:
  - 웨이브 시스템
  - 적 스폰 관리
  - 난이도 단계적 상향
  - 점수 시스템
  - 게임 오버 관리

### 4. UI 매니저 ✅
- **파일**: `src/scripts/ui_manager.gd`
- **기능**:
  - 실시간 체력바 (예정)
  - 점수 표시
  - 웨이브 정보
  - 게임 오버 화면
