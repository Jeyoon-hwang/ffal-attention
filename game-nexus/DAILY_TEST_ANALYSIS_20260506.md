## ⚖️ 현재 밸런싱 수치 분석

### 플레이어 기본 밸런싱

```
체력 (HP):           120
에너지 (Energy):     100
정기 (Spirit):       100

기본 공격:           20 damage
└─ 콤보 1:          20 dmg
└─ 콤보 2:          26 dmg (+30% bonus)
└─ 콤보 3:          32 dmg (+60% bonus)

무술 스킬:           45 damage (30 energy cost)
스킬 쿨:             1.2초

내공 활성화:         1.5배 데미지 배수
내공 소비:           5/sec
```

**평가**: 🟢 균형 잡혀 있음
- 플레이어는 충분한 유지력 (에너지)이 있음
- 공격력은 적당 (적 기본 공격 12보다 1.67배)
- 콤보 보너스가 있어서 연타 장려

---

### 적 기본 밸런싱

```
기본 적:
  체력 (50) × 레벨 multiplier
  └─ 초급 (1): 50 HP
  └─ 중급 (2): 75 HP
  └─ 고급 (3): 125 HP

기본 공격: 12 damage (× 레벨 multiplier)
  └─ 초급 (1): 12 dmg
  └─ 중급 (2): 16.8 dmg
  └─ 고급 (3): 21.6 dmg

스킬 사용 확률:
  └─ 초급 (1): 20% (cooldown 2.0초)
  └─ 중급 (2): 40%
  └─ 고급 (3): 60%

스킬 데미지: 12 × 2.0 = 24 damage (× 레벨)
  └─ 초급: 24 dmg
  └─ 중급: 33.6 dmg
  └─ 고급: 43.2 dmg
```

**평가**: 🟡 약간 약함?
- 고급 적이라도 플레이어의 기본 공격 3연타(32dmg)보다 체력이 125만 있음
- 플레이어가 스킬 없이도 충분히 승리 가능
- **개선 필요**: 적 체력을 약간 상향?

---

### 보스 밸런싱

```
보스 체력:  280 (최근 개선: 200 → 280)
보스 공격:  30 damage (× 파당 multiplier)
보스 스킬:  60 damage (2배, 60% 확률)

패턴:
  - 기본 공격
  - 연속 공격
  - 광범위 스킬

보스 스케일링:
  정파: 1.0배 (균형)
  사파: 0.9배 (빠르지만 약함)
  독립: 1.2배 (강함)
```

**평가**: 🟢 적절함
- 플레이어가 내공을 사용해야 충분히 도전적
- 체력이 이제 적당한 수준

## 🐛 발견된 이슈 & 개선사항

### 1. 적 난이도 밸런싱
**우선도**: 🟡 중간

**현황**:
- 초급 적: 약간 약함 (50HP, 12dmg)
- 중급 적: 적당함 (75HP, 16.8dmg)
- 고급 적: 약간 약함 (125HP, 21.6dmg)

**개선안**:
```gd
// constants.gd 수정
const ENEMY_HEALTH_MULTIPLIERS = {
	1: 1.2,    # 초급: 60 HP (이전 50)
	2: 1.8,    # 중급: 90 HP (이전 75)
	3: 3.0     # 고급: 150 HP (이전 125)
}

const ENEMY_DAMAGE_MULTIPLIERS = {
	1: 1.1,    # 초급: 13.2 dmg (이전 12)
	2: 1.5,    # 중급: 18 dmg (이전 16.8)
	3: 2.0     # 고급: 24 dmg (이전 21.6)
}
```

**효과**:
- 초급 적이 조금 더 도전적
- 중급, 고급 적이 충분히 위협적
- 플레이어가 적어도 2-3체 상대는 신경써야 함

---

### 2. 스테이지 난이도 곡선 완화
**우선도**: 🟡 중간

**현황**:
```
const GAME_STAGE_DIFFICULTY_INCREMENT = 0.15  # 15% per stage
```

**문제점**:
- Stage 10에서 적 체력이 4배 이상 증가
- 무한반복이 금방 불가능하게 됨

**개선안**:
```gd
// constants.gd 수정
const GAME_STAGE_DIFFICULTY_INCREMENT = 0.10  # 10% per stage (이전 15%)
```

**효과**:
- Stage 10: 2.59배 (이전 4.05배)
- 더 오래 플레이 가능
- 점진적인 난이도 상승

---

### 3. 플레이어 에너지 회복 속도 재검토
**우선도**: 🟢 낮음

**현황**:
```
const PLAYER_ENERGY_RECOVERY_RATE = 2.5  # (이전 5.0에서 감소)
```

**분석**:

- 플레이어가 기본 공격 중심 플레이

**평가**: 🟢 적당함 (현재 수치 유지)
