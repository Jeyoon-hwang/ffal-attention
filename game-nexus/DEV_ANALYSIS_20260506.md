## 🐛 발견된 이슈 & 개선사항

### Issue 1: 매직 넘버 (Magic Numbers)
**위치**: player.gd, enemy.gd, game_manager.gd  
**심각도**: 중간  
**내용**: 하드코딩된 값들이 산재
```gdscript
# 현재 (안 좋음)
energy = min(energy + 5 * delta, max_energy)

# 개선
const ENERGY_RECOVERY_RATE = 5.0
energy = min(energy + ENERGY_RECOVERY_RATE * delta, max_energy)
```

### Issue 2: 에너지 회복 밸런스
**심각도**: 높음  
**내용**: 5/delta가 너무 빨면 스킬이 무가치해짐
**제안**: 현재 5 → 2-3으로 조정

### Issue 3: 콤보 타이머
**심각도**: 중간  
**내용**: 0.6초 윈도우가 너무 짧을 수 있음
**제안**: 0.6 → 0.8-1.0으로 조정

### Issue 4: 적 스킬 사용 확률
**심각도**: 낮음  
**내용**: skill_chance가 초급(1)/중급(2)/고급(3)에 무관
**제안**: 무술 레벨에 따라 확률 조정

### Issue 5: 보스 체력
**심각도**: 중간  
**내용**: 200 HP는 너무 낮을 수 있음 (플레이어 120 HP)
**제안**: 난이도 고려하여 250-300으로 상향
