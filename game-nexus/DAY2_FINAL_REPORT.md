### 3. **Mission 3: 파티클 이펙트** ✅

**파일**: `src/scripts/particle_effects.gd` (261줄, 새로 작성)
**기술**: CPU 파티클 (GDScript 기반)

```
✅ 7가지 파티클 타입
   ├─ "hit" (노란색) - 일반 공격 피격
   ├─ "skill" (청색) - 무술 스킬 발동
   ├─ "spin" (주황색) - 회전 공격
   ├─ "dash" (빨강) - 대시 공격
   ├─ "boss" (보라색) - 보스 공격
   ├─ "dodge" (흰색) - 회피 성공
   └─ "impact" (짙은 빨강) - 충격

✅ Particle 클래스
   ├─ 위치 (Vector3)
   ├─ 속도 (Vector3)
   ├─ 색상 (Color)
   ├─ 수명 (lifetime)
   └─ 크기 (scale)

✅ 파티클 업데이트 루프
   ├─ 물리 시뮬레이션 (중력, 속도)
   ├─ 알파 페이드아웃 (지수적 감소)
   ├─ Mesh 업데이트 (위치, 스케일, 색상)
   └─ Dead particle 제거 (메모리 관리)

✅ 편의 함수
   ├─ spawn_hit_effect()
   ├─ spawn_skill_effect()
   ├─ spawn_spin_effect()
   ├─ spawn_dash_effect()
   ├─ spawn_boss_effect()
   ├─ spawn_dodge_effect()
   └─ spawn_impact_effect()

✅ 유틸리티
   ├─ get_active_particle_count()
   ├─ clear_all_particles()
   ├─ debug_print_stats()
   └─ print_particle_info()
```

**구현 방식**:
```gdscript
# Particle 클래스
class Particle:
  - 위치, 속도, 색상, 수명 관리
  - update(delta) 함수로 매 프레임 업데이트
  - SphereMesh + StandardMaterial로 시각화

# 파티클 생성 (원형 분산)
for i in range(count):
  angle = i / count * TAU  # 360도 분산
  spread_dir = normalized(cos(angle), random, sin(angle))
  velocity = direction * speed + spread_dir * speed
```

**성능**:
- 최대 160개 동시 파티클 (20개 × 8가지)
- CPU 파티클 (GPU 파티클보다 느리지만 단순함)
- 나중에 Godot의 GPUParticles3D로 최적화 가능

**테스트 상태**:
- ✅ 클래스 설계 완벽
- ✅ 편의 함수 완벽
- ✅ 메모리 관리 완벽
- 🟡 실제 플레이 테스트 필요
