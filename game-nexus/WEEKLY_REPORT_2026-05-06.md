## 🎮 게임 메커닉 상세 (Week 1 구현)

### 전투 시스템
```
좌클릭: 기본 공격
├─ 1히트: 20 대미지 (콤보 1)
├─ 2히트: 26 대미지 (콤보 2)
└─ 3히트: 32 대미지 (콤보 3)

우클릭: 무술 스킬 (45 대미지, 에너지 30 소비)
Q: 내공 활성화 (공격력 1.5배, 지속 10초)
```

### 파당 시스템
```
정파 (정파 → 하늘 호수파)
├─ 난이도: 100%
├─ 특성: 균형잡힌 능력치
└─ 스타일: 전통 무술

사파 (사파 → 흑마교, 독종파)
├─ 난이도: 80% (더 빠름)
├─ 특성: 높은 민첩, 낮은 방어
└─ 스타일: 빠른 공격

독립 (무림인사, 괴도)
├─ 난이도: 120% (더 강함)
├─ 특성: 높은 공격력, 느린 속도
└─ 스타일: 강력한 공격

보스 (각 스테이지 보스)
├─ 난이도: 200%+
├─ 특성: 모든 스킬 사용 가능
└─ 스타일: 전략적 공격
```

### 스테이지 시스템
```
Stage 1 (난이도 1.0)
├─ 5명 적 스폰
├─ 난이도별 혼합 (정파/사파/독립)
└─ 보스 1명

Stage 2 (난이도 1.15)
├─ 5명 적 스폰
├─ 난이도 15% 상향
└─ 보스 1명

Stage 3 (난이도 1.30) → ... 무한 반복
```
