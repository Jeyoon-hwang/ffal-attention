## 🐛 발견 & 수정된 버그 (7개)

### 1. 입력 설정 누락 ✅
- **심각도**: 🔴 높음
- **파일**: project.godot
- **문제**: `ui_focus_next`, `ui_cut` 액션 미정의
- **영향**: 플레이어 스킬/내공 기능 사용 불가
- **수정**: 입력 매핑 추가

### 2. Godot 4 API 호환성 ✅
- **심각도**: 🔴 높음
- **파일**: player.gd, enemy.gd
- **문제**: `velocity = move_and_slide(velocity)` (Godot 3.x 스타일)
- **영향**: 플레이어/적 이동 불가능
- **수정**: `velocity = move_and_slide()` (Godot 4 형식)

### 3. 플레이어 씬 미포함 ✅
- **심각도**: 🔴 **극심**
- **파일**: main.tscn
- **문제**: 플레이어 노드 완전 누락
- **영향**: **게임 실행 불가능** (가장 치명적!)
- **수정**: Player 씬 인스턴스 추가

### 4. CollisionShape3D 미설정 ✅
- **심각도**: 🔴 높음
- **파일**: player.tscn, enemy.tscn
- **문제**: CollisionShape3D가 shape 속성 미설정
- **영향**: 3D 물리 충돌 감지 불가능
- **수정**: BoxShape3D / CapsuleShape3D 추가

### 5. Godot 메타 형식 오류 ✅
- **심각도**: 🟡 중간
- **파일**: player.tscn, enemy.tscn, main.tscn
- **문제**: `[meta groups=["..."]]` (Godot 3.x)
- **영향**: 그룹 태그 미작동
- **수정**: Godot 4 `groups = ["..."]` 형식으로 변경

### 6. 플레이어 공격 로직 불완전 ✅
- **심각도**: 🔴 **극심**
- **파일**: player.gd
- **문제**: `basic_attack()`, `skill_attack()` 함수가 실제로 데미지 입히지 않음
- **영향**: **플레이어가 적을 공격할 수 없음!** (게임 불가능)
- **수정**: AttackArea 범위 감지 + 적 데미지 처리 추가

### 7. is_attacking 플래그 관리 오류 ✅
- **심각도**: 🟡 중간
- **파일**: player.gd
- **문제**: `is_attacking` 플래그가 리셋되지 않음
- **영향**: 공격 상태 무한 지속
- **수정**: 공격 애니메이션 종료 후 플래그 리셋

   - 초기 씬 구조 설계가 매우 중요

3. **공격 로직의 실제 구현**
   - Print만 하는 것은 게임이 아님
   - 실제 게임 로직이 필수
