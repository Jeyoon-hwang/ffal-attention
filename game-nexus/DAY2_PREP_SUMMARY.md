## 🎯 Day 2의 5개 미션

### Mission 1: 3D 환경 프로토타입 (2-3시간)
```
목표: 첫 지역(중원) 기본 레이아웃
결과물: zhongyuan_hub.tscn

구현 사항:
  ✅ 계획: SCENE_DESIGN_ZHONGYUAN.md에서 완전히 설계됨
  □ 실행: 200m × 200m 맵 구성
    ├─ 마을 중앙 (광장 + 건물 5개)
    ├─ 훈련장 (적 스폰 영역)
    ├─ 보스 아레나 (원형, 경계선)
    ├─ 10개 던전 입구
    ├─ 나무 10개
    ├─ 다리 3개
    └─ 경계 벽 4개
    
  □ 테스트: 플레이어 스포닝, 이동, 적 스폰 확인

예상 시간: 10:00-12:00
```

### Mission 2: 보스 AI 구현 (2-3시간)
```
목표: 첫 보스(명월검사) 구현 및 3가지 패턴
결과물: boss_ai.gd 확장, 실제 보스 전투

구현 사항:
  ✅ 계획: WEEK1_DAY2_PLAN.md에서 패턴 상세 설계
  □ 실행: 보스 패턴 시스템
    ├─ 패턴 1: 기본 연타 (3회, 90 대미지)
    ├─ 패턴 2: 광역 회전 (80 대미지, 광역)
    └─ 패턴 3: 강력 슷 (50 대미지 + 넉백)
    
  □ 로직: HP에 따른 패턴 전환
    ├─ HP 100%-70%: 패턴 1
    ├─ HP 70%-40%: 패턴 2
    └─ HP 40%-0%: 패턴 3
    
  □ 테스트: 실제 보스 전투, 난이도 검증

예상 시간: 12:00-14:00
```

### Mission 3: 파티클 이펙트 (1.5-2시간)
```
목표: 공격/스킬 시각적 피드백 5개 파티클 추가
결과물: spawn_particle_hit() 함수 + 5개 이펙트

구현 사항:
  ✅ 계획: WEEK1_DAY2_PLAN.md에서 이펙트 정의
  □ 실행: 5개 파티클 이펙트
    ├─ 기본 공격: 흰색 스매시
    ├─ 무술 스킬: 파란색 에너지
    ├─ 회전 공격: 노란색 광역
    ├─ 대시 공격: 빨간색 궤적
    └─ 보스 패턴: 보라색 강력함
    
  □ 통합: player.gd, enemy.gd, boss_ai.gd에 연결
  □ 최적화: 메모리 누수 방지 (자동 정리)
  □ 테스트: 시각적 피드백 확인

예상 시간: 14:00-15:30
```

### Mission 4: 무술 창조 UI (2-2.5시간)
```
목표: 게임 화면에 필요한 정보 표시 (HUD)
결과물: GameHUD.tscn + 바 그래픽

구현 사항:
  ✅ 계획: WEEK1_DAY2_PLAN.md에서 UI 설계
  □ 실행: HUD 시스템
    ├─ 플레이어 체력 바 (초록색)
    ├─ 에너지 바 (파란색)
    ├─ 내공 바 (노란색)
    ├─ 보스 체력 바 (빨간색)
    ├─ 콤보 카운터 (텍스트)
    └─ 전투 로그 (스크롤)
    
  □ 함수: update_all_hud() - 실시간 업데이트
  □ 바인딩: player.gd, boss_ai.gd와 연동
  □ 테스트: 실시간 업데이트 확인, UI 겹침 확인

예상 시간: 15:30-18:00
```

### Mission 5: 게임 실행 테스트 (1-2시간)
```
목표: 통합 테스트 + 버그 발견 & 수정
결과물: 안정적인 게임, 테스트 리포트

구현 사항:

  □ 실행: 4가지 시나리오 테스트

    ├─ Scenario B: UI 체크 (바 업데이트, 로그)
    ├─ Scenario C: 파티클 확인 (이펙트 표시)
    └─ Scenario D: 밸런싱 검증 (데미지, 난이도)

    ├─ 높은 심각도: 즉시 수정
    ├─ 중간 심각도: 기록 후 우선순위 정함
    └─ 낮은 심각도: 리스트 업데이트
    
  □ 성능 측정: FPS, 메모리, CPU 확인
  □ 리포트: 테스트 결과 문서화
```
