### 3️⃣ 새 기능: 회전 공격 (스핀 어택) ✨

#### 기능 설명
- **키**: E (새로운 입력 액션: ui_spin)
- **데미지**: 35 (기본 공격 20의 1.75배)
- **에너지 소비**: 20 (스킬 30보다 적음)
- **쿨타임**: 2.0초
- **효과**: 360도 모든 방향의 적에게 데미지

#### 코드 구현
```gdscript
func spin_attack():
    """회전 공격 - 모든 방향의 적에게 데미지"""
    if spin_attack_timer > 0:  # 쿨타임 체크
        return
    
    if energy >= SPIN_ATTACK_ENERGY_COST:
        # 에너지 소비
        energy -= SPIN_ATTACK_ENERGY_COST
        spin_attack_timer = SPIN_ATTACK_COOLDOWN
        
        # 데미지 계산 (내공 영향 포함)
        var damage = PLAYER_SPIN_ATTACK_DAMAGE
        if is_spirit_active:
            damage *= PLAYER_SPIRIT_DAMAGE_MULTIPLIER
        
        # 반경 범위 내 모든 적에게 데미지
        # (PhysicsShapeQueryParameters3D + SphereShape3D 사용)
        # 범위: 8.0 유닛 (전체 방향)
```

#### 전략적 의미
```
기본 공격 (좌클릭 X):
  → 짧은 쿨, 낮은 에너지 (0)
  → 콤보 가능 (1.75x 최고)
  
무술 스킬 (우클릭):
  → 중간 쿨 (1.2초), 높은 에너지 (30)
  → 높은 데미지 (45)
  → 범위 공격

회전 공격 (E) - NEW:
  → 긴 쿨 (2.0초), 중간 에너지 (20)
  → 중간 데미지 (35)
  → 360도 전방위 공격
  → 여러 적 동시 타격 최적
```

**효과**:
- 플레이어가 다양한 전투 옵션 보유
- 5명 적 상대할 때 효과적
- 게임 플레이 깊이 증가

## 📊 게임 밸런싱 최종 평가

### 플레이어 vs 초급 적
```
플레이어 공격: 20 (기본) ~ 32 (콤보 3) ~ 45 (스킬) ~ 35 (회전)
초급 적 공격:  13.2
초급 적 체력:  60

분석:
- 플레이어 기본 3연타 (32 dmg) > 초급 적 체력 (60)
- 플레이어는 약 2번의 콤보로 초급 적 처치 가능
- 밸런스: 적절함 ✅
```

### 플레이어 vs 중급 적
```
플레이어 공격: 20 ~ 32 ~ 45 ~ 35
중급 적 공격:  18
중급 적 체력:  90

분석:
- 플레이어 기본 3연타 (32 dmg) < 중급 적 체력 (90)
- 플레이어는 3-4번의 콤보 + 스킬 필요
- 중급 적의 공격 (18)은 무시할 수 없는 수준
- 밸런스: 적절함 ✅
```

### 플레이어 vs 고급 적
```
플레이어 공격: 20 ~ 32 ~ 45 ~ 35
고급 적 공격:  24
고급 적 체력:  150

분석:
- 플레이어는 스킬+회전공격+콤보 조합 필요
- 고급 적의 공격 (24)은 상당한 위협
- 플레이어는 내공 활성화 권장 (1.5배 데미지)
- 밸런스: 도전적 ✅
```

### 보스 전투
```
플레이어: 120 HP, 최대 45 damage (스킬)
보스: 280 HP, 30 damage (공격)

분석:
- 플레이어는 스킬을 6-7회 사용해야 보스 처치 가능
- 내공 활성화 시: 스킬 45 * 1.5 = 67.5 → 약 4-5회
- 보스의 공격 (30)은 상당한 위협
- 플레이어는 회복 아이템이나 회피 능력 필요
- 밸런스: 도전적 ✅
```

**최종 평가**: 🟢 **전반적으로 균형잡혀 있음**
