**"세상에 없던 무술을 만들고, 그걸로 세상을 정복한다."**

플레이어가 **기초 무술 요소들을 자유롭게 조합**해서 자신만의 무술을 창조하고, 그 무술로 적을 무찌르고, 더 강한 무술을 발견하며, 궁극의 무술을 완성하는 게임.

## ⚔️ 무술 창조 시스템 (핵심)

### 무술 생성 공식
```
무술 = 기초 + 스타일 + 패턴 + 효과 조합
```

### 1. 기초 무술 10가지
```
1. 검법 (Sword)      - 근거리, 빠른 공격
2. 창법 (Spear)      - 중거리, 길이 활용
3. 도법 (Saber)      - 근거리, 강한 힘
4. 봉법 (Staff)      - 중거리, 광역 공격
5. 권법 (Boxing)     - 근거리, 연타
6. 발차 (Kicking)    - 중거리, 높은 위력
7. 내공 (Chi)        - 원거리, 에너지파
8. 암기 (Dagger)     - 근거리, 빠른 모션
9. 채찍 (Whip)       - 원거리, 유동적
10. 빈수 (Unarmed)   - 근거리, 기초 기술
```

### 2. 스타일 20가지
```
우아함, 광포함, 신비성, 정확성, 강력함,
빠르기, 방어성, 회피성, 분노, 차분함,
매력, 냉정함, 열정, 균형, 폭발성,
우아함, 부드러움, 거친성, 신성함, 저주
```

### 3. 패턴 30가지
```
- 기본 공격 (1단, 2단, 3단)
- 광역 공격 (회전, 점프, 지진)
- 연타 공격 (2~5연, 무한)
- 이동 공격 (돌진, 점프, 이동)
- 방어 공격 (반격, 블록 후 공격)
- 특수 공격 (정지 후 강공격, 누적 후 폭발)
- 조건부 공격 (피격 후, 킬 후, HP 낮을 때)
- 버프 공격 (공격력 증가, 속도 증가)
- 혼합 공격 (여러 기법 혼합)
- 최종기 (누적 → 필살기)
```

### 4. 효과 50가지
```
대미지 타입 (물리, 에너지, 독, 화염, 냉기, 전기)
상태이상 (중독, 화상, 빙결, 마비, 광기, 저주)
통계 버프 (공격력, 방어력, 속도, 치명타)
이동 효과 (넉백, 끌어당김, 회전, 부양)
생명 효과 (회복, 흡수, 버틸, 면역)
시간 효과 (가속, 감속, 정지)
장판 효과 (거미줄, 불, 얼음, 독)
시야 효과 (눈부심, 어둠, 홀림)
음성 (외침, 음파, 음악)
복합 (여러 효과 혼합)
```

### 생성 가능한 무술 수

```
기초 10 × 스타일 20 × 패턴 30 × 효과 50
= 300만 가지 기본 조합

+ 고급 조합 (2가지 효과, 3가지 효과)
= 수백만 개 가능
```

### 무술 발견 방식

#### 📖 고서 발견 (200개)
- 월드곳곳에 숨겨짐
- 읽으면 기초 요소 습득
- 예: "태양검법" → 검법 + 화염 효과 습득

#### 👨‍🏫 NPC 스승 (90-130명)
- 각 지역에 스승들 위치
- 스승과 대련 → 그 스승의 무술 학습
- 예: "광검의 대가" 스승과 대련 → 검법 + 광포함 스타일 습득

#### 🗡️ 몬스터 전투 경험
- 몬스터와 전투 중 특정 공격 방식 사용
- 반복하면 그 기술 자동 습득
- 예: 3연타 100번 사용 → "삼단연격" 패턴 습득

#### 🏆 던전 보상
- 각 던전 클리어 → 새 무술 요소 획득
- 난이도 높을수록 좋은 요소

#### 💡 자각 창조 (플레이어 창작)
- 습득한 요소들을 자유롭게 조합
- 조합하면 새로운 무술 생성
- 예: "검법 + 화염 + 광역 회전 + 신비성"
  → "불타는 나선검" 창조!

## 🎮 전투 시스템

### 플레이어 전투

#### 기본 조작
```
WASD        → 이동
마우스      → 시점
Space       → 점프
좌클릭      → 무술 1 사용
우클릭      → 무술 2 사용
Q           → 내공 활성화 (버프)
E           → 특수 기능 (지역별)
```

#### 무술 활용
- **무술 슬롯**: 2개 활성화 (자유 교체)
- **쿨타임**: 각 무술마다 개별 관리
- **에너지**: 무술 사용 시 소비, 시간으로 회복
- **내공**: 활성화 시 공격력 1.5배, 에너지 추가 소비

#### 전투 메커닉
```
무술 사용
  ↓
판정 (거리, 장애물, 반사)
  ↓
적중 확인
  ↓
대미지 + 효과 적용
  ↓
상태이상/버프 처리
```

### 적 AI

#### AI 난이도 4단계
```
1. 초급: 기본 공격만, 느린 반응
2. 중급: 2가지 무술, 회피 시도
3. 상급: 3가지 무술, 전술적 이동
4. 신급: 모든 무술, 완벽한 AI
```

#### AI 행동 패턴
```
- 추격: 플레이어 거리 계산
- 공격 선택: 거리/HP에 따른 최적 선택
- 회피: 플레이어 공격 예측 후 회피
- 버프: 상황에 맞춰 자체 버프 활성화
- 팀 전술: 여러 적이 함께 공격
```
