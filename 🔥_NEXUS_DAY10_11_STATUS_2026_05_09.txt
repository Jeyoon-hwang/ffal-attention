🎯 기술 하이라이트
───────────────────────────────────────────────────────────────────────────

1. 데이터 주도 설계 (Data-Driven)
   → NPC, 지역, 던전을 데이터베이스로 정의
   → 새로운 콘텐츠 추가가 코드 수정 없이 가능

2. 시그널 기반 아키텍처
   → zone_entered, dungeon_cleared 등 이벤트 신호
   → UI와 게임로직이 느슨하게 결합 (loosely coupled)
   → 확장성 높음

3. 동적 생성 시스템
   → 지역 진입 시 동적으로 NPC 배치
   → 던전 진입 시 동적으로 방 생성
   → 메모리 효율성 높음

4. 게임플레이 파이프라인
   → 지역 → NPC → 던전 → 클리어 → 보상
   → 순차적이고 명확한 흐름
   → 완전히 검증된 게임 경험
