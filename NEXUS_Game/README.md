## 🎮 게임 소개

**NEXUS**는 무술을 자유롭게 창조하고, 거대한 세계에서 전투하는 혁신적인 3D RPG입니다.

### ⚡ 주요 특징

- **🥋 무술 창조 시스템**
  - 50가지 기본 무술 × 8가지 변형 = 수백만 가지 조합
  - 자유롭게 무술을 설계하고 테스트하는 경험
  - 나만의 스타일 찾기

- **🗺️ 거대한 세계**
  - 5개 지역 (중원, 동산, 서해, 남방, 북극)
  - 50-70개의 던전 탐험
  - 각 지역 500m × 500m의 넓은 맵

- **🎯 깊이 있는 전투**
  - 4단계 AI 난이도 (초급 ~ 신급)
  - 200+가지 무술 조합 전투
  - 전략적인 보스 전투

- **📖 풍부한 스토리**
  - 100+명의 NPC와 상호작용
  - 200+가지 퀘스트
  - 5개 지역별 깊이 있는 스토리

- **🎬 고품질 그래픽**
  - 3D 캐릭터 & 환경
  - 200+가지 애니메이션
  - 실시간 파티클 이펙트

- **🎵 몰입감 있는 사운드**
  - 배경음악 (전투, 마을, 보스)
  - 풍부한 효과음
  - 한국어 음성 (기초)

## 🚀 설치 방법

### Windows

1. **NEXUS_Game_Windows.zip** 다운로드
2. 폴더 해제
3. `NEXUS.exe` 실행
4. 게임 시작!

### macOS

1. **NEXUS_Game_macOS.zip** 다운로드
2. 폴더 해제
3. `NEXUS.app` 더블클릭
4. 보안 경고 시: **우클릭** → **열기** 클릭
5. 게임 시작!

### Linux

```bash
chmod +x NEXUS_Game_Linux/NEXUS
./NEXUS_Game_Linux/NEXUS
```

## 🎮 플레이 가이드

### 기본 조작

| 키 | 기능 |
|---|---|
| **WASD** | 이동 |
| **마우스** | 카메라 조작 |
| **E** | 상호작용 (NPC, 아이템) |
| **I** | 인벤토리 열기 |
| **S** | 스킬 메뉴 |
| **T** | 무술 창조 |
| **ESC** | 메뉴 |

### 전투 시스템

1. **무술 장착**
   - 인벤토리에서 무술 선택
   - 핫키에 등록 (1-8번)

2. **공격하기**
   - 숫자 키 (1-8) 또는 마우스 클릭
   - 콤보 시스템 (같은 무술 연속 사용)
   - 내공 관리 (MP 소비)

3. **전투 전략**
   - 적의 패턴 학습
   - 약점 찾기
   - 콤보로 데미지 극대화

### 무술 창조

1. **기본 무술 선택** (5가지 Base)
   - 검술, 도술, 권법, 창법, 봉법

2. **특성 추가** (8가지 Modifier)
   - 빠르게 (SPD +30%)
   - 강력하게 (ATK +40%)
   - 멀리 (Range +50%)
   - 등등...

3. **무술 테스트**
   - 연습장에서 시험
   - 데미지, 콤보 확인

4. **전투에 사용**
   - 창조한 무술 장착
   - 실제 전투에서 활용

## 📖 스토리

### 프롤로그
당신은 한 수행자의 꿈을 가진 젊은이. 신비한 물러 **NEXUS**의 부름을 받아 중원에 도착한다.

중원은 혼돈의 호랑이의 공포에 떨고 있다. 현지 촌장은 당신에게 호랑이 처치를 부탁한다.

### 5개 지역의 여정
1. **중원** - 시작점, 호랑이와의 첫 전투
2. **동산** - 도사의 비법을 배우는 곳
3. **서해** - 검객들의 무술 거리
4. **남방** - 신비로운 숲과 고대 유물
5. **북극** - 최강 무사들의 무덤

### 엔딩
당신이 모든 보스를 물리치고, 세 가지 무술을 마스터할 때, 진실이 드러난다...
