### 4️⃣ Skill Tree UI (`engine/skill_tree_ui.gd`)

**구조:**
```
5개 브랜치 (각 3단계):
  STR (빨강):    강화된 검술 → 맹렬한 참격 → 괴력의 경지
  DEX (청록):    민첩한 동작 → 그림자 선수 → 분신의 술
  INT (자홍):    기본 마법 → 원소의 힘 → 마법의 대가
  VIT (초록):    체력 단련 → 강인한 체질 → 불멸의 신체
  WIS (노랑):    통찰력 → 영혼 감지 → 천의 눈
```

**기능:**
- 스킬 포인트 관리
- 브랜치별 스킬 습득
- 능력치 보너스 표시
- 포인트 부족 시 습득 불가

**특징:**
- 색상 코딩된 브랜치
- 비용 기반 습득 시스템
- 스킬 상세 정보 표시

**파일 크기:** 6,342 bytes
