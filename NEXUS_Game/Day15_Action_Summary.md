### Blender Automation
```python
# 특징: 3줄 명령으로 모든 모델 생성 가능
blender --background --python script.py

# 결과: 모두 assets/Models/에 자동 정렬
# 속도: 각 모델 0.001초 (매우 빠름)
```

```gdscript

importer.scan_and_import_assets()

# 사용: 게임 시작 시 자동 로드
var character = importer.load_character("male")
```
