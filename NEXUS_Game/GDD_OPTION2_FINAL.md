## 🎮 게임 시스템

### 1. 무술 창조 엔진 (Combat System Core)

#### 1.1 무술의 구성요소 (6개 축)

```
무술 = Base (5가지) 
       + Modifier (방향, 속도, 범위, 부작용)
       + Combo Link (연쇄)
       + Stat Scaling (능력치 가중)
       + Animation (시각)
       + Sound (청각)
```

**Base 무술 (5가지 기본 타입):**
1. **베기 (Slash)** — 일반적, 빠름, 낮은 계수
2. **찌르기 (Thrust)** — 중간 속도, 중간 계수, 정밀
3. **내려찍기 (Smash)** — 느림, 높은 계수, 넓은 범위
4. **에너지 방사 (Wave)** — 원거리, 마나 소비, 높은 계수
5. **특수 기술 (Special)** — 복합 효과, 긴 캐스팅

#### 1.2 Modifier 시스템 (동적 변형)

각 무술에 적용 가능한 수정자:

| Modifier | 효과 | 마나/체력 | 쿨타임 영향 |
|----------|------|---------|-----------|
| 빠르게 (Quick) | 공격속도 +40%, 데미지 -20% | +5 | -20% |
| 강하게 (Heavy) | 데미지 +60%, 공격속도 -30% | +15 | +30% |
| 넓게 (Wide) | 범위 +150%, 데미지 -15% | +10 | +15% |
| 좁게 (Precise) | 명중률 +50%, 크리티컬 +25% | -5 | -10% |
| 관통 (Pierce) | 방어 무시 50% | +20 | +20% |
| 연쇄 (Chain) | 최대 3개 적에게 순차 공격 | +30 | +40% |
| 회복 (Drain) | 데미지의 30% 회복 | +40 | +50% |
| 독성 (Poison) | 3초 독 상태 (초당 10% HP) | +25 | +25% |

#### 1.3 능력치 가중치 (Stat Scaling)

```
Damage = Base_Damage × (1 + STR×0.8 + DEX×0.2 + [ModifierBonus])
```

- **STR (근력):** 베기, 내려찍기 (80% 적용)
- **DEX (민첩):** 찌르기, 에너지 (60% 적용), 회피율 영향
- **INT (지능):** 에너지 방사 (100% 적용), 마나 최대치
- **VIT (체력):** 체력 최대치, 방어력
- **WIS (지혜):** 쿨타임 단축 (5% per 1 WIS), MP 재생

#### 1.4 Combo System (연쇄)

- **기본 콤보:** 같은 무술 3회 연속 → 데미지 +30%
- **크로스 콤보:** 서로 다른 무술 5개 순차 → 보너스 데미지 +50%, 특수 이펙트
- **프로 콤보:** 플레이어 커스텀 콤보 (최대 7개 무술 조합)
  - 가중치 설정 (우선순위)
  - 타이밍 윈도우 자동 계산

### 2. 플레이어 캐릭터 시스템

#### 2.1 능력치 (8가지)

```
STR (근력): 0-100 | DEX (민첩): 0-100 | INT (지능): 0-100 | VIT (체력): 0-100
WIS (지혜): 0-100 | CHA (매력): 0-100 | LCK (행운): 0-100 | RES (저항): 0-100
```

**레벨 UP 방식:**
- 매 레벨 5 포인트 자유 배분
- 퀘스트 완료 + 특정 무술 사용 시 해당 능력치 자동 증가
- 장비 착용 시 추가 보너스

#### 2.2 직업 (클래스)

| 클래스 | STR | DEX | INT | VIT | WIS | CHA | 특성 |
|--------|-----|-----|-----|-----|-----|-----|------|
| 검사 (Swordsman) | +15 | +10 | 0 | +10 | 0 | 0 | 무술 2개 동시 장착, 기본 공격 +20% |
| 궁수 (Archer) | +5 | +20 | +5 | 0 | 0 | 0 | 원거리 무술 +30%, 회피율 +15% |
| 마도사 (Mage) | -10 | +5 | +25 | -5 | +20 | 0 | 에너지 무술 +50%, MP +40%, 이동속도 +10% |
| 도적 (Rogue) | +8 | +25 | 0 | -5 | +5 | +20 | 크리티컬 +30%, 은신 가능, 회피율 +20% |
| 기사 (Paladin) | +15 | 0 | +5 | +15 | +10 | +10 | 방어력 +40%, 회복 아이템 효율 +50%, HP +30% |
| 음유시인 (Bard) | 0 | +10 | +10 | 0 | +10 | +25 | 버프/디버프 +40%, 아군 강화 가능 |

### 3. 적 AI 시스템 (4단계)

#### Level 1: 기본 AI (초급 적)
- 거리 기반 공격 선택
- 플레이어 거리 유지
- 조건부 회피 (HP < 30%)

#### Level 2: 전술 AI (중급 적)
- 플레이어 패턴 학습 (3초 윈도우)
- 약한 적에게 집중 공격
- 강력한 무술 조합 사용 (40% 확률)

#### Level 3: 적응형 AI (고급 적/소보스)
- 실시간 약점 분석
- 지형 활용 (높이, 장애물)
- 멀티 페이즈 전투 (HP 구간별 패턴 변경)

#### Level 4: 마스터 AI (보스/최강 적)
- 완전한 전술 적응
- 플레이어 위협 감지 시 합동 공격
- 확률 기반 카운터 무술 사용 (70% 명중률로 가장 효율 높은 응수)
- 스페셜 페이즈: 엔레이지 (공격속도 +50%, 데미지 +40%, 쿨타임 -40%)

- **퀘스트:** 50개
- **보상:** 고급 장비, 고급 무술서, 희귀 재료

### 5. 콘텐츠 시스템

#### 5.1 퀘스트 타입

| 타입 | 설명 | 보상 |
|-----|------|------|
| 메인 퀘스트 | 스토리 진행 (30개) | EXP +200%, 무술서 |
| 부가 퀘스트 | 캐릭터 발전 (100개) | EXP +100%, 장비 |
| 수집 퀘스트 | 아이템 수집 (40개) | 골드, 재료 |
| 몬스터 헌팅 | 특정 몬스터 처치 (30개) | 경험치 +300% |

#### 5.2 장비 시스템

- **아이템 레어도:** 일반 → 희귀 → 영웅 → 전설 → 신성 (5단계)
- **장비 슬롯:** 머리, 가슴, 다리, 발, 손, 반지 (x2), 목걸이
- **강화 시스템:** +0 ~ +20 (재료 필요)
- **각성 시스템:** 고급 장비는 특수 능력 활성화 가능

#### 5.3 무술서 시스템

- **획득 방식:** 퀘스트, 던전 보상, NPC 구매
- **습득 방식:** 무술서 사용 → 새로운 무술 학습
- **무술 분류:**
  - 기본 무술 (Base 5가지)
  - 중급 무술 (수정된 조합, 50+개)
  - 고급 무술 (시너지, 100+개)
  - 전설 무술 (엔드게임, 20개)

### 6. 스토리 & 내러티브

#### 메인 스토리 아크 (총 30시간)

1. **프롤로그:** 평범한 무인의 등장
2. **Act 1 (중원):** 무술 깨우침, 첫 번째 위협 마주침
3. **Act 2 (얼음 봉우리):** 과거의 비밀 발견, 강적 등장
4. **Act 3 (마그마 분화):** 세계의 진실 깨달음, 최강자의 시험
5. **Act 4 (어둠의 숲):** 내면과의 대면, 운명의 선택
6. **Act 5 (신의 영역):** 최종 결전, 세계를 바꾸는 힘

#### 주요 NPC (중요 캐릭터)

- **은사 (Mentor):** 처음 무술을 가르쳐주는 NPC
- **라이벌:** 비슷한 수준의 무인, 경쟁과 협력
- **연인:** 감정 연결, 선택지 기반 엔딩 분기
- **악역:** 세계를 삼키려는 암흑의 세력

### 7. 기술 & 전투 메커닉

#### 7.1 전투 시스템

```
Turn = 플레이어 입력 + 적 AI 결정 (동시 계산)
     → 데미지 계산 (능력치 + 무술 + 수정자)
     → 상태 이상 적용
     → 다음 턴으로
```

- **쿨타임 시스템:** 무술마다 다름 (0.5초 ~ 30초)
- **마나/에너지:** MP 최대치 기반, 무술마다 소비량 다름
- **회피/방어:** DEX와 VIT 기반, 확률 계산

#### 7.2 캐릭터 진행

```
레벨 1 → 50 (50시간 플레이)
각 10레벨 = 새로운 무술 습득 기회
```

## 🎨 그래픽 & 폴리시

### 예상 비주얼

- **스타일:** Semi-realistic + 판타지 감성
- **캐릭터:** 고해상도 모델 (4K, 8K 텍스처)
- **이펙트:** 무술별 고유 이펙트 (파티클, 라이팅, 블룸)
- **월드:** 각 지역별 고유 색감과 분위기

### AAA급 폴리시 체크리스트

- ✅ 모든 무술에 독특한 비주얼 이펙트
- ✅ 모든 공격 타입별 사운드 (20+가지)
- ✅ 캐릭터 모션 애니메이션 (100+)
- ✅ 환경 상호작용 (부서지는 벽, 떨어지는 돌 등)
- ✅ 카메라 연출 (보스 공격 시 드라마틱한 줌, 회전)
- ✅ UI/UX 세련되고 명확함
- ✅ 로딩 시간 최소화 (2초 이하)

## 📊 개발 타임라인 & 진도율

| 주차 | 목표 | 진도율 |
|-----|------|--------|
| 1-2주 | 엔진 & 기초 (무술 생성, 전투, 첫 지역 프로토) | 0% → 20% |
| 3-4주 | 그래픽 & 애니메이션 (3D 모델, 이펙트) | 20% → 35% |
| 5-6주 | 콘텐츠 폭발 (던전, NPC, 퀘스트) | 35% → 60% |
| 7-8주 | 심화 & 엔드게임 (모든 지역, 보스) | 60% → 80% |
| 9-10주 | 최적화 & 폴리시 (성능, UI, 밸런싱) | 80% → 95% |
| 11-12주 | 최종 폴리시 & 출시 (버그 픽스, 튜닝) | 95% → 100% |

## ✅ 완성 기준

- **에러 0 (Zero-Error Game)**
  - 크래시 없음
  - 진행 불가 버그 없음
  - 밸런스 이슈 최소화
  
- **AAA급 완성도**
  - 모든 콘텐츠 유니크한 경험 제공
  - 그래픽 & 사운드 일관성 있음
  - 플레이 시간 예상 범위 달성 (30-50시간)

- **재미 보장**
  - 무술 창조의 즐거움
  - 강함에 대한 욕구 충족
  - 엔드게임 콘텐츠 풍부
