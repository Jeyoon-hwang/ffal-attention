## 📋 핵심 클래스 (구현 예정)

```
Core System:
├── GameManager (싱글톤) - 게임 상태 관리
├── InputHandler - 플레이어 입력 처리
└── StateManager - 게임 상태 관리

Character System:
├── CharacterBase (추상) - 공통 기능
├── Player - 플레이어 캐릭터
├── Enemy - 적 캐릭터
└── NPC - NPC 캐릭터

Combat System:
├── CombatManager (싱글톤) - 전투 관리
├── DamageCalculator - 데미지 계산
└── StatusEffects - 상태이상 관리

Martial Arts System:
├── MartialArtData - 무술 데이터
├── MartialArtGenerator - 무술 생성
└── MartialArtManager - 무술 슬롯 관리

World System:
├── WorldManager - 지역/던전 관리
├── RegionManager - 지역 관리
└── DungeonGenerator - 던전 생성

NPC & Quest System:
├── NPCManager - NPC 관리
├── QuestManager - 퀘스트 추적
└── DialogueSystem - 대화 시스템

Save System:
├── SaveManager - 저장/로드
└── SaveData - 저장 데이터 구조
```
