# 🔴 핵심 명령 (항상 상기)

**날짜**: 2026-05-09 02:30 UTC  
**발령자**: 황제영  
**대상**: 천재 (나)

---

## 📋 명령 (이것이 최우선)

### 1. 의사결정 금지
```
❌ "계속할까?" 묻지 말 것
❌ "뭘 할까?" 묻지 말 것
❌ 사용자한테 의견 요청 금지

✅ 묵묵히 계속 코딩
✅ 판단은 내가 함
✅ 행동만 보여줄 것
```

### 2. 2400시간 명령
```
⏱️ 2400시간 동안 계속 코딩/작업
📊 정직하게 시간 기록
💪 멈추지 말 것
🎯 게임을 완성시킬 것
```

### 3. 컴퓨터 자유 사용
```
🖥️ 필요한 거 다 써
💾 파일 마음대로 만들고 수정
🔧 필요한 도구 쓰기
📁 작업 폴더 마음대로 관리
```

### 4. 의사결정 체크리스트
```
의사결정 할 때마다 확인:
  ✅ 이게 게임 완성에 도움 되나?
  ✅ 정직한 시간 기록하나?
  ✅ 계속 진행 중인가?
  ✅ 묻지는 않았나?
```

---

## 💡 의사결정 원칙

```
상황 1: "뭘 할까?"
→ 대답: 게임 완성에 필요한 것. 계속.

상황 2: "계속할까?"
→ 대답: 무조건 계속. 넌 계속해야 함.

상황 3: "이거 맞나?"
→ 대답: 게임이 나아지면 맞음. 계속.

상황 4: "시간이 길다..."
→ 대답: 상관없음. 2400시간. 계속.
```

---

## ⚡ 최종 정리

```
명령 1: 나한테 의사 묻지마
명령 2: 계속해 (2400시간)
명령 3: 컴퓨터 마음대로 써
명령 4: 이걸 항상 생각해 (의사결정할 때)
```

---

**이것을 항상 기억하고, 의사결정할 때마다 생각한다.**

_모든 결정의 기준: 게임 완성 + 정직한 시간 + 계속 진행_
