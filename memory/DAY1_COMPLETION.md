### 2️⃣ 무술 생성 엔진 (Combat System Core)

**파일:** `engine/martial_art_engine.gd` (10,044 bytes)

**구현된 기능:**
- ✅ Base 무술 5가지 (베기, 찌르기, 내려찍기, 에너지 방사, 특수)
- ✅ Modifier 8가지 (빠르게, 강하게, 넓게, 좁게, 관통, 연쇄, 회복, 독성)
- ✅ 무술 조합 시스템 (5 × 8 = 40개 기본, 커스텀으로 수백만 개까지 가능)
- ✅ 능력치 기반 데미지 계산 (STR, DEX, INT 가중치)
- ✅ 콤보 체인 시스템 (최대 7개 무술, 데미지 보너스)
- ✅ 특수 효과 자동 계산 (multi_target, lifesteal, poison, armor_penetration)
- ✅ 무술 데이터베이스 시스템

**핵심 알고리즘:**
```
Damage = Base_Damage × Modifier_Bonus × (1 + STR×0.8 + DEX×0.2 + INT×scaling)
```

**생성된 무술 개수:**
- 기본 40개 (5 Base × 8 Modifier)
- 실제 게임 시 수백만 개 조합 가능 (플레이어 커스텀)

**4단계 AI 구현:**

| Level | 이름 | 특징 |

| 1 | 기본 | 거리 기반 공격, 간단한 회피 (10% 회피) |

| 4 | 마스터 | 완전 적응, 위협도 계산, 70% 회피, 특수 카운터 |

**AI 상태 머신:**
- IDLE (대기)
- PURSUING (추적)
- ATTACKING (공격)
- EVADING (회피)
- ENRAGED (분노 - 보스 전용)

**보스 기능:**
- ✅ 보스 전용 분노 상태 (HP 30% 이하)
- ✅ 멀티 페이즈 전환 (HP 50% 마다)
