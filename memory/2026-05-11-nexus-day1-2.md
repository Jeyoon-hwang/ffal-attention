#### 3. 핵심 클래스 구현

**MartialArt.gd (1,056줄)**
- 무술 데이터 구조 완전 구현
- 11가지 기본 동작 (주먹, 발차기, 콤보, 특수 공격)
- 리듬(Tempo), 방어 타입, 판정 박스 시스템
- 8가지 상태 이상 효과 (기절, 다운, 넉백, 둔화, 출혈, 화염, 빙결, 독)
- 클론, 유효성 검증, 레벨 업, 통계 기능

**MartialArtDatabase.gd (1,268줄)**
- 싱글톤 패턴 (Autoload)
- 100개 기본 무술 로드 (자동 생성)
- 커스텀 무술 저장/로드
- 난이도별 필터, 난수 생성
- 플레이어 무술 로드아웃 생성 (5슬롯)

**Character.gd (1,489줄)**
- 캐릭터 기본 클래스 (Player, Enemy, Boss 부모)
- 6가지 스탯 (STR, DEX, CON, INT, WIS, CHA)
- HP & 에너지 시스템
- 무술 슬롯 관리 (5개)
- 상태 이상 관리 (스턴, 둔화 등)
- 전투 신호/이벤트 시스템
- 시뮬레이션 기능

**CombatSystem.gd (1,278줄)**
- 싱글톤 패턴 (Autoload)
- 데미지 계산 (STR × 무술파워 + DEX × 크리티컬)
- 크리티컬 확률 및 배수 (1.5x)
- 상태 이상 적용 (8가지)
- 콤보 시스템 (x1.0 ~ x2.0 배수)
- 속성 상성 계산
- 무술 밸런싱 (위력 vs 에너지 트레이드오프)
- 전투 시뮬레이션

**GameManager.gd (1,114줄)**
- 싱글톤 패턴 (Autoload)
- 게임 상태 관리 (menu, loading, gameplay, paused, game_over)
- 플레이어 생성 & 관리
- 장면 로드
- 게임 저장/로드 (3개 슬롯)
- 게임 통계 (플레이 시간, 처치 적 수, 현재 레벨)
- JSON 파일 기반 저장 시스템

#### 4. 데이터 생성

**martial_arts.json (100개 무술)**
- Python 스크립트로 자동 생성
- 10개 난이도 × 10개 템플릿
- 각 무술: 위력, 에너지 비용, 쿨타임, 판정 범위 등
