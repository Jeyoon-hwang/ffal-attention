## 🔥 특이사항 & 결정사항

### 무술 슬롯 설계
- **왜 5개인가?**: 기본/특수/방어/회피/궁극기 구성 가능
- **랜덤 배치**: 플레이마다 다른 무술 조합 경험
- **개별 쿨다운**: 슬롯별로 독립적인 쿨타임 관리

### JSON 로드 방식
- **Godot FileAccess + JSON 파서**: 표준 방식
- **res:// 프리픽스**: 프로젝트 상대 경로 사용
- **게임 시작 시 한 번 로드**: 성능 최적화

### 키 바인딩 선택
- **1-5**: 간단하고 직관적
- **대체안**: Q-E-R-F-G도 가능하지만 WASD와 충돌 가능성
