```

```

### 회피 시스템 구현
```
플레이어 공격
  ↓
enemy.try_dodge() 호출
  ↓
회피율 확인 (Level별 다름)
  ↓
회피 성공 → 데미지 스킵 + 메시지 출력
회피 실패 → enemy.take_damage() 호출
```

→ 플레이어를 역습 (2.5배 데미지)
→ 플레이어도 입장 마찬가지
