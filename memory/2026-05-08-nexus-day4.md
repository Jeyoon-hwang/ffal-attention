### 기술 구조

```
게임 시작
  ↓
GameManager._ready()
  ├─ MartialArtEngine 로드
  ├─ 싱글톤으로 "/root/MartialArtEngine" 등록
  └─ Player._ready() 호출
    └─ load_martial_arts()
      ├─ MartialArtEngine 접근
      ├─ martial_arts_base_set.json 로드 (30개)
      └─ initialize_martial_slots() 호출
        └─ 5개 슬롯에 랜덤 무술 배치

플레이 중
  ↓
키 입력 (1-5)
  ↓
_input() 이벤트 처리
  ↓
use_martial_art(slot)
  ├─ 쿨다운 확인
  ├─ 에너지 확인
  ├─ 무술 발동
  └─ 쿨다운 설정

매 프레임
  ↓
_physics_process(delta)
  └─ 모든 슬롯의 쿨다운 감소
```
