#### Day 3-4: 핵심 엔진 구현
1. **MartialArt.gd** (무술 데이터 구조)
   - 기본 동작, 리듬, 방어 타입, 에너지 비용
   - 판정 박스, 상태 효과, 파워
   - 레벨 & 강화 시스템
   - JSON 저장/로드 인터페이스

2. **MartialArtEngine.gd** (무술 생성 엔진)
   - 기본 동작 100가지 데이터베이스
   - 기본 무술 10개 템플릿 (펀치, 킥, 방어, 특수기 등)
   - 랜덤 무술 생성 (수백만 조합 가능)
   - 무술 강화 & 조합 시스템
   - 무술 검색/필터링 기능

3. **Player.gd** (플레이어 캐릭터)
   - 6개 기본 스탯 (STR, DEX, CON, INT, WIS, CHA)
   - HP & Energy 시스템
   - 무술 슬롯 5개 관리
   - 입력 처리 (마우스, 키보드)
   - 회피, 방어, 콤보 시스템
   - 상태이상 관리
   - 경험치 & 레벨업 시스템

4. **Enemy.gd** (적 AI)
   - **Level 1 AI (동물형)**
     - 기본 공격 패턴
     - 거리 기반 추격 & 공격
     - 간단한 회피
   
   - **Level 2 AI (기초 무술사)**
     - 무술 3-4가지
     - 플레이어 행동 패턴 학습
     - 상태 머신 (Idle → Chase → Attack → Dodge)
     - 회피 & 방어 사용

5. **CombatSystem.gd** (전투 시스템)
   - 데미지 계산 엔진
   - 콤보 보너스 시스템
   - 상태이상 처리
   - 전투 통계 추적
   - 보상 처리 (경험치, 골드)

6. **GameManager.gd** (게임 상태 관리)
   - 무술 엔진 초기화
   - 플레이어 생성
   - 전투 시스템 통합
   - 게임 상태 관리

7. **test_combat.gd** (테스트 씬)
   - 간단한 입력 테스트
   - 전투 루프 검증
