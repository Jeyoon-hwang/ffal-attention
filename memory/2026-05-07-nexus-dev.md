## Day 2 완료 (22:30-현재, 약 3시간)

### 핵심 클래스 구현

1. **MartialArt.gd** (3.8 KB) ✅
   - 무술 데이터 구조 (id, name, power, energy_cost, effects 등)
   - `calculate_damage()`: 데미지 계산
   - `upgrade()`: 레벨 강화
   - `to_dict() / from_dict()`: 직렬화

2. **Player.gd** (7.2 KB) ✅
   - CharacterBody3D 상속
   - 스탯 시스템 (STR, DEX, CON, INT, WIS, CHA)
   - HP/Energy 관리 (100/100 기본)
   - 5개 무술 슬롯
   - 입력 처리: WASD(이동), 1-4(공격), 마우스우클릭(방어), Space(회피)
   - 공격/방어/회피 로직
   - 상태 효과 시스템 (화염, 빙결, 기절 등)

3. **Enemy.gd** (6.6 KB) ✅
   - CharacterBody3D 상속
   - AI 상태 머신 (idle → chase → attack)
   - AI 레벨별 파라미터
     - Level 1: perception_range=10, move_speed=4
     - Level 4: perception_range=30, move_speed=7
   - 플레이어 감지 & 추격
   - 공격 로직 (기본 공격 + 무술)
   - 죽음 & 보상 시스템

4. **MartialArtEngine.gd** (7.2 KB) ✅
   - 싱글톤 무술 관리 엔진
   - 기본 4개 무술 탑재 (뜨거운 주먹, 빙결 발차기, 철벽 방어, 그림자 회피)
   - `generate_random_martial()`: 무술 생성
   - `save_martial_art() / load_martial_art()`: JSON 저장/로드
   - 프래그먼트 시스템 (수집 & 해금)

5. **CombatSystem.gd** (3.8 KB) ✅
   - 싱글톤 전투 시스템
   - `calculate_final_damage()`: 최종 데미지
   - `get_targets_in_hitbox()`: 히트박스 판정
   - `apply_status_effect()`: 효과 적용

6. **CombatTest.tscn** ✅
   - 테스트용 3D 씬
   - Ground, Camera, DirectionalLight, Player, Enemy1, MartialArtEngine
