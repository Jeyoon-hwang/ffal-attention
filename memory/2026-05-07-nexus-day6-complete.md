#### 4. **SkillTreeUI** (스킬 트리)

  - STR (빨강): 강화된 검술 → 맹렬한 참격 → 괴력의 경지
  - DEX (청록): 민첩한 동작 → 그림자 선수 → 분신의 술
  - INT (자홍): 기본 마법 → 원소의 힘 → 마법의 대가
  - VIT (초록): 체력 단련 → 강인한 체질 → 불멸의 신체
  - WIS (노랑): 통찰력 → 영혼 감지 → 천의 눈
- 스킬 포인트 시스템 (레벨업 시 +1)
- 비용 기반 습득 (1~3 포인트)

#### 5. **MapSystem** (월드맵/미니맵)
- 5개 지역 (500m × 500m):

  2. 동산 (회색) [미발견]
  3. 서해 (청록) [미발견]
  4. 남빙원 (연파랑) [미발견]
  5. 북황무지 (주황) [미발견]
- 격자 기반 렌더링
- 지역별 던전 4개 (Lv. 1, 5, 10, 20)
- 텔레포트 시스템 (발견된 지역만)

#### 6. **MenuSystem** (메뉴)
- 메인 메뉴 (새게임, 계속, 설정, 종료)
- 설정 메뉴 (음량, 밝기, 그래픽 품질)
- 상태 기반 관리

#### 7. **PauseMenuUI** (일시정지 메뉴)

- ESC 키 토글

#### 8. **OptimizationEngine** (성능 최적화)
