#### Day 5: 플레이어 전투 심화 - 방어 + 회피 ✅

**추가 구현:**
```
Constants.gd에 추가:
- PLAYER_DEFENSE_DAMAGE_MULTIPLIER = 0.5 (방어 중 50% 피해만)
- PLAYER_DEFENSE_ENERGY_COST_PER_SEC = 1.0
- PLAYER_DODGE_ENERGY_COST = 25
- PLAYER_DODGE_COOLDOWN = 0.5
- PLAYER_DODGE_I_FRAME_DURATION = 0.3 (무적 시간)
- PLAYER_DODGE_SPEED_MULTIPLIER = 2.5

Player.gd에 추가:
- is_defending (방어 상태)
- is_dodging (회피 중)
- dodge_cooldown_timer (회피 쿨다운)
- current_i_frames (무적 시간 남은 시간)

함수:
- start_defending() / stop_defending() (우클릭)
- attempt_dodge() (Space)
- apply_defense_energy_cost() (초당 에너지 소비)
- take_damage() 수정 (방어/무적 상태 확인)

입력 처리:
- 우클릭 (ui_focus_next): 방어 시작/종료 (누르기/놓기)
- Space (ui_accept) + 지면: 점프 또는 방어 중이면 회피
```

**현황:**
- 콤보 시스템: ✅ 동작
- 에너지 회복: ✅ 초당 2.5 회복
- 방어: ✅ 50% 피해 감소, 에너지 소비
- 회피: ✅ 0.3초 무적, 0.5초 쿨타임, 에너지 소비
- 내공: ✅ 대미지 1.5배, 초당 소비
