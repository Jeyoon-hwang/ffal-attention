## 🎯 Day 17 - 게임 최종 통합 & 콘텐츠 완성 (70% 도달)

### Phase 1: 게임 실행 및 검증 (1시간)

**목표**: 게임이 정상 작동하는지 최종 확인

1. **MainGameAdvanced 씬 실행**
   - Godot에서 열기
   - 에러 로그 확인
   - 초기화 성공 확인

2. **GameIntegration 초기화 확인**
   - 모든 시스템 로드됨
   - 콘솔에 에러 없음
   - 게임 상태 "playing" 확인

3. **Player 스탯 확인**
   - Level 1, EXP 0
   - HP/Energy 최대
   - 무술 슬롯 준비됨

### Phase 2: CenterZone 최종 완성 (1.5시간)

**목표**: CenterZone을 완전히 플레이 가능하게

1. **NPC 통합**
   - 4명 배치 (Master, Merchant, Elder, Guard)
   - 상호작용 스크립트 동작
   - 대사 및 UI 표시

2. **Enemy 전투**
   - Wolf 3마리 배치
   - Goblin 2마리 배치
   - 전투 가능 확인

3. **Props 배치**
   - 건물, 나무, 불, 게이트 등 배치
   - 콜리전 설정 확인

4. **퀘스트 연결**
   - "learn_basics" 시작 가능
   - "first_kill" 클리어 가능
   - 보상 획득 가능

### Phase 3: Dungeon 1-3 플레이 가능하게 (1.5시간)

**목표**: 3개 던전을 모두 플레이 가능하게

1. **BeginnerCave 완성**
   - 3 Floors 생성
   - 각 Floor에 Enemy 2-3마리
   - 보상 지급 시스템

2. **DarkCavern 완성**
   - 5 Floors 생성
   - Mixed Enemies (Wolf + Goblin)
   - Boss 방 준비

3. **GoblinLair 완성**
   - 7 Floors 생성
   - Goblin-only Enemies
   - Boss 방 준비

4. **Dungeon 진입 흐름**
   - CenterZone → Dungeon 진입 가능
   - 던전 클리어 시 보상 획득
   - 던전 → CenterZone 복귀 가능

### Phase 4: Boss 전투 완성 (1시간)

**목표**: Boss 1을 플레이 가능하게

1. **BossTower 씬 생성**
   - Boss 1마리 배치
   - 전투 트리거 설정

2. **Boss AI 검증**
   - 3-Phase 시스템 작동
   - 패턴 변경 확인
   - 데미지 계산 정상

3. **Boss 전투 흐름**
   - Player vs Boss 전투 가능
   - Boss 패턴 다양함
   - Boss 사망 시 보상 획득
   - 게임 승리 화면 표시

### Phase 5: 게임 루프 최종 통합 (1시간)

**목표**: 처음부터 끝까지 플레이 가능하게

1. **메인 메뉴 → 게임**
   - Main Menu 접근
   - "New Game" 선택
   - CenterZone 로드

2. **전체 흐름 테스트**
   - CenterZone 플레이 (5분)
   - Dungeon 1-3 진입 (10분)
   - Boss 전투 (5분)
   - Game Over 화면 (1분)

3. **최종 확인**
   - 에러 없음 ✅
   - 모든 콘텐츠 접근 가능 ✅
   - 게임 완주 가능 ✅
