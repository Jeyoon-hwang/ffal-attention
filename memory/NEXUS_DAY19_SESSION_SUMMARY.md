## 기술 내용

### 협력 스킬 4가지
1. **연쇄 공격** (2초 쿨) - 플레이어 공격 후 동료 즉시 1.3배 데미지
2. **호응 방어** (3초 쿨) - 플레이어 피해 시 35% 흡수
3. **동시 공격** (5초 쿨) - 플레이어/동료 동시 공격 1.5배 데미지
4. **치유 지원** (6초 쿨) - 플레이어 HP <50% 시 20% 회복

### 협력도 시스템
```
협력도 = 기본 0.7 + 콤보 보너스(최대 +0.2) + HP 보너스
최대: 1.0 (완벽한 협력)
```

### 보상 시스템
```
최종 보상 = 기본 × 난이도배수 × 협력보너스(1.3~1.5) + 상호작용보너스
```
