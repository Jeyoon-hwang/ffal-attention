## 🎯 Day 6 즉시 실행 계획

### 1단계: 추가 적 종류 생성 (2시간)

**Rogue.gd** - Level 2-3 도적
```gdscript
extends Enemy

func _ready():
    name = "Rogue"
    level = 2
    max_hp = 50
    hp = 50
    martial_arts = [
        MartialArtEngine.get_martial_art("quick_strike"),
        MartialArtEngine.get_martial_art("shadow_clone")
    ]
    ai_level = 2
    perception_range = 12
    move_speed = 5.5  # 빠름
    attack_cooldown = 1.2  # 자주 공격
```

특징:
- 빠른 공격
- 에너지 효율이 좋음
- 약한 체력
- 회피 능력 높음

**Swordmaster.gd** - Level 3-4 검사
```
- 강한 공격력 (데미지 +30%)
- 느린 공격속도
- 높은 체력
- AI Level 3 (약점 감지)
```

**Mage.gd** - Level 3-4 마법사
```
- 낮은 체력
- 마법 공격 (원거리)
- 회피 능력 중간
- 상태 이상 능력 (화염, 빙결)
```

**Golem.gd** - Level 4-5 골렘
```
- 매우 높은 체력 (300+)
- 느린 공격
- 낮은 이동 속도
- 특수 능력: 돌 방어 (데미지 감소)
```

**Undead.gd** - Level 4-5 언데드
```

- 그룹 공격 (여러 무술)
- 부활 능력 (죽었다 다시 나타남)
```
